# REBU

Paid video & voice calling and live-streaming app with hosts.

| Folder | What | Stack |
|---|---|---|
| `mobile/` | User & host app (Android / iOS) | React Native CLI (JavaScript) |
| `frontend/` | Web modules — admin panel now (`src/modules/admin`), website & agency panels later | React + Vite |
| `backend/` | API (not started yet) | Node.js + MongoDB |

See `frontend/README.md` to run the admin panel. The mobile app runs with `npx react-native start` and `android/gradlew app:installDebug`.
